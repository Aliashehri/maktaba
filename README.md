# مكتبة الكتب — دليل مختصر

## إضافة كتاب (للدكتور)
1. افتح صفحة الإدارة: `رابط-الموقع/admin.html`
2. أول مرة فقط: الصق مفتاح GitHub واضغط «حفظ والاتصال».
3. اكتب اسم الكتاب، واختر الغلاف (اختياري) وملف PDF، ثم اضغط «نشر الكتاب».
4. يظهر الكتاب في الموقع خلال دقيقة إلى ثلاث دقائق.

من نفس الصفحة: تعديل الاسم، تغيير الغلاف، الترتيب، الحذف، عنوان المكتبة، وتفعيل زر التحميل.

## طريقة احتياطية بدون صفحة الإدارة
ارفع ملف PDF مباشرة إلى مجلد `books` في GitHub، وسيظهر في الموقع تلقائياً.
ولو أردت غلافاً: ارفع صورة بنفس اسم الملف إلى مجلد `covers` (مثال: `books/kitab.pdf` و `covers/kitab.jpg`).

## ملاحظات
- يُفضّل ألا يتجاوز حجم الكتاب 30 ميجابايت حتى يفتح بسرعة على الجوال.
- إذا ظهرت رسالة «انتهت صلاحية المفتاح»: أنشئ مفتاحاً جديداً من GitHub (الخطوات موجودة في صفحة الإدارة).
- لا يحتاج الموقع أي تحديثات أو صيانة، وكل المكتبات والخطوط محفوظة داخله.
